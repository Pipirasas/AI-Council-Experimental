# Security policy

**R0 is an experimental research preview, not a security-reviewed tool.** It should not be used to make safety-critical or security-critical decisions.

Do **not** put sensitive proofs of concept, secrets, access tokens or exploitable private details into public Issues or Discussions. At the public repository launch, the maintainer must enable GitHub **Private vulnerability reporting** (Security settings). Then use the repository's **Report a vulnerability** workflow.

If private reporting has not yet been enabled, open an Issue asking only for a secure contact mechanism, **without disclosing vulnerability details**. No personal contact email is part of this release candidate.

Supported release scope: only the R0 experimental source snapshot. No general security guarantees are provided.
