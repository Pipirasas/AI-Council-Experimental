# Roadmap (proposed)

**R0:** Release a dependency-free, offline evidence-validation core with synthetic fixtures, clear licensing, contributor workflow and zero private-history transfer. Require owner publication approval.

**R1:** Make evidence broker behavior and `COMPLETE`/`INCOMPLETE` semantics easier to test and integrate. Add artifact-free examples and cross-platform regression coverage.

**R2:** Design and evaluate a model adapter behind explicit inputs, controlled budgets and auditable outputs; no automatic access to protected datasets.

**R3:** Construct a reproducible, preregistered strong-single-model comparison and independent adjudication methodology. Use synthetic/public examples for development; preserve blind evaluation sets.

**Future:** GUI, multiple local backends, performance, maintainability and independently measured comparative reliability.

This is a **proposal**, not a claim of delivered functionality or authorized live inference.
