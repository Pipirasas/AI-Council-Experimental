# Governance (experimental phase)

**Lead maintainer:** [@Pipirasas](https://github.com/Pipirasas).

The lead maintainer determines scope, evidence standards, security boundaries, accepted code, release timing and future maintainers. Contributors may propose changes using Issues and PRs; review is merit-based and does not convey automatic repository write access.

Contributors can improve code and tests without access to private qualification datasets. Public synthetic tests and protected blind evaluations serve different purposes. Do not request publication of protected sets as a condition for accepting a PR.

The project is in development. No claims that Council outperforms a strong single model should be made until a preregistered, independent, cost-matched evaluation supports that claim.
