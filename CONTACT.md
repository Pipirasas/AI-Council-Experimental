# Contact and discussion

For bug reports, technical proposals, first-time contributions or questions, open a **GitHub Issue** with a minimal, synthetic, reproducible example. Use **GitHub Discussions** for general design questions when that feature is enabled.

There is **no project contact email published at R0**. Contributors should not seek the maintainer's personal email or post sensitive code, secrets, system logs or protected evaluation cases in public threads.

**Security-sensitive matters:** follow [SECURITY.md](SECURITY.md), not a detailed public Issue. At public launch, the maintainer must enable GitHub private vulnerability reporting. Until the repository's **Report a vulnerability** option is available, request a secure contact mechanism without disclosing sensitive details.
